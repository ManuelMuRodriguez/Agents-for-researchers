    Curso practico para investigadores

    Usa un asistente en Visual Studio Code para traducir codigo, documentar, versionar y reproducir entornos.

    ~60 min VS Code MATLAB + Python Git + Docker

    Objetivo docente

    Que puedan abrir un proyecto real, entenderlo rapido y automatizar tareas frecuentes con prompts claros y reproducibles.

    Que es un agente en VS Code

    No es un chat generico: vive dentro del editor y entiende el contexto completo de tus archivos y proyecto.

    📝 Escribe y edita codigo

    Genera funciones, refactoriza y corrige errores directamente en el archivo activo.

    💡 Explica en lenguaje natural

    Describe que hace cualquier fragmento como si lo escribieras en un correo.

    🔭 Ve el proyecto completo

    Con @codebase o @workspace analiza todo el repositorio de una vez.

    🔁 Responde donde trabajas

    No necesitas salir de VS Code. La respuesta llega al editor, no a una pestana externa.

    Por que usarlo en investigacion

    Sin asistente
    • ✕Busquedas largas en documentacion
    • ✕Traduccion manual entre lenguajes
    • ✕Documentacion que siempre queda pendiente
    • ✕Entornos que no arrancan en otra maquina
    Con asistente
    • ✓Respuesta contextual en segundos
    • ✓Traduccion rapida con estructura conservada
    • ✓Documentacion generada al momento
    • ✓Entornos reproducibles con Docker

    Chat e Inline

    💬 Chat lateral

    Tareas grandes, preguntas de arquitectura o analisis completo del proyecto.

    ⚡ Inline Ctrl+I

    Cambios rapidos sobre lineas seleccionadas sin salir del editor.

    🗜️ Compactar

    Resume el historial de chat para quitar ruido sin tocar los archivos del proyecto.

    Primer prompt recomendado para cualquier proyecto:
    @codebase explicame que hace este proyecto y por donde empieza la ejecucion

    Menu @: que usar y cuando

    🔭 Contexto y analisis

    • @codebase / @workspace — entender proyectos grandes
    • @changes — revisar que se ha modificado recientemente
    • @file — centrar el contexto en un archivo concreto

    🚀 Ejecucion y entorno

    • @agent — tareas largas de varios pasos automatizados
    • @terminal — interactuar con la terminal desde el chat
    • @configurePythonEnvironment — preparar entorno Python
    Consejo: empieza siempre con @codebase para que el agente tenga todo el contexto antes de pedir cambios.

    MATLAB en VS Code

    1️⃣
    Instala la extension oficial

    Busca "MATLAB" en el Marketplace de VS Code e instalala.

    2️⃣
    Configura la ruta del ejecutable

    Apunta a tu instalacion local de MATLAB en los ajustes de VS Code.

    3️⃣
    Ejecuta con F5

    Abre un .m y presiona F5 para lanzar el script completo (no el boton de seccion).

    4️⃣
    Usa el chat para mejorar

    Pide al asistente que explique, corrija errores o traduzca el script a Python.

    Demo principal: traducir MATLAB a Python

    Tu escribes en el Chat: "Traduce este script de MATLAB a Python usando numpy, pandas y matplotlib"
    Traduce este script de MATLAB a Python 3. Usa numpy para calculos, pandas para CSV y matplotlib para graficas. Manten la estructura de secciones y comentarios.
    Salida esperada: invernadero.py generado por los participantes en directo

    Git y GitHub en 3 pasos

    📁
    1 · git add .

    Prepara todos los cambios para el commit

    💬
    2 · git commit

    Copilot escribe el mensaje a partir de los cambios actuales

    ☁️
    3 · git push

    Tu codigo en la nube, seguro y compartible

    git add . git commit -m "mensaje generado por Copilot" git push origin main

    Docker Compose (simple)

    🐳 Docker es como una "fiambrera" que contiene tu codigo, librerias y version de Python. Donde lo abras, funciona exactamente igual.
    Sin Docker
    • ✕En mi maquina funciona...
    • ✕Dependencias distintas entre equipos
    • ✕El revisor no puede ejecutar tu codigo
    • ✕Horas reinstalando librerias
    Con Docker
    • ✓Mismo entorno en cualquier maquina
    • ✓requirements.txt + compose = reproducible
    • ✓El revisor ejecuta con un comando
    • ✓Ciencia reproducible real
    docker compose up

    Practica guiada

    Caso real: sensores de un invernadero — 7 dias de temperatura, humedad, CO2 y viento con eventos de fallo simulados.
    🔭
    A
    Explorar el proyecto

    Usa @codebase para entender la estructura y que hace invernadero.m

    🔄
    B
    Traducir a Python

    Prompt guiado para generar invernadero.py con numpy, pandas y matplotlib

    🐳
    C
    Lanzar con Docker

    Ejecutar el script generado con docker compose up en entorno reproducible

    Funcionalidades seleccionadas para el ejercicio

    🌡️ Heatmaps

    Mapas de calor por hora del dia vs dia de la semana para T_int_C, H_int_pct y CO2_ppm.

    3 subplots · colorbar · titulos listos para presentacion

    📊 Resumen diario

    Minimo, maximo y media de cada sensor agrupados por dia de medicion.

    Salida: resumen_diario_invernadero.csv

    🔗 Correlacion

    Matriz de correlacion de Pearson entre todos los sensores del invernadero.

    Tabla + heatmap + correlacion_sensores.csv

    Prompt 1: heatmaps

    Elige el archivo invernadero.py en el Chat y escribe:
    Anade mapas de calor por hora del dia vs dia de la semana para T_int_C, H_int_pct y CO2_ppm. Usa 3 subplots, colorbar y titulos listos para presentacion.
    Resultado esperado: figura con 3 heatmaps lista para incluir en publicacion

    Prompt 2: resumen diario

    Con el archivo abierto en el Chat:
    Calcula un resumen diario para todos los sensores: minimo, maximo y media por dia. Guarda en resumen_diario_invernadero.csv.
    Resultado esperado: resumen_diario_invernadero.csv con 7 filas y columnas min/max/mean

    Prompt 3: correlacion

    Con el archivo abierto en el Chat:
    Calcula la matriz de correlacion de Pearson entre sensores. Muestrala como tabla y tambien como heatmap con etiquetas. Guarda en correlacion_sensores.csv.
    Resultado esperado: correlacion_sensores.csv + heatmap con valores Pearson

    Tips para clase

    🎯 Contexto primero

    Empieza siempre con @codebase para que el agente entienda el proyecto antes de pedir cambios.

    📁 Salidas reproducibles

    Pide siempre que guarde CSV y figuras con nombre fijo para que los resultados sean auditables.

    👁️ Validacion visual

    Antes de confiar en el resultado, revisa una grafica rapida. El asistente puede equivocarse en los ejes.
